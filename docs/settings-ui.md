# 设置页界面约定

以现有设置页为视觉基准。新增清单源区域沿用偏好设置、在线 Markdown 和本地导入的元素样式。

## 现有样式基准

所有尺寸基于页面 `fontSize` 计算，颜色直接使用现有 `AppThemeTokens`。

| 元素 | 约定 |
| --- | --- |
| 页面标题 | 1.25 倍字号、粗体、强调色 |
| 设置项标题 | 0.95 倍字号、普通字重、次要文字色 |
| 说明 | 0.75 倍字号、次要文字色、沿用原说明透明度 |
| 卡片 | 横向内距 0.9 倍、圆角 0.8 倍、边框 0.07 倍 |
| 胶囊操作 | 0.85 倍字号、横向内距 0.6 倍、使用 chip 系列颜色 |
| 列表行 | 名称 0.9 倍、链接 0.75 倍、右侧轻量文字操作 |
| 输入框 | 0.8 倍字号、页面底色、0.5 倍圆角、横向内距 0.6 倍 |

`SettingsControls.ets` 将新增区域的胶囊按钮和输入框提取为复用组件，其样式来自原设置页。清单源列表复用 Markdown 列表的名称、链接、右侧操作布局；刷新使用浅色胶囊，添加、恢复使用选中胶囊色。

清单源与同步状态继续通过显式属性更新，错误信息完整显示并支持复制，官方源移除后保留恢复入口。

## 验收重点

对照原界面检查方向、语言、主题的紧凑横排和配色，核对清单源与 Markdown 区域的字号、间距、输入框和操作样式。清单源添加只填写目录地址，名称由域名自动生成，同名追加 `_2`、`_3` 等后缀。真机验证深浅色、横屏、地址输入与同步状态；完成后恢复用户原来的主题和屏幕方向。
